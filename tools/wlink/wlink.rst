wlink
=====

wlink - WCH-Link(RV) command line tool

https://github.com/ch32-rs/wlink

简介
----

wlink 是一个用于 WCH-Link(RV) 调试器的命令行工具，支持通过命令行接口与 WCH-Link(RV) 进行交互，实现固件下载、调试控制等功能。

特性
----
- 支持 WCH-Link(RV) 调试器
- 通过命令行进行固件下载与调试操作
- 跨平台支持（Windows、Linux、macOS）
- 易于集成到自动化构建与测试流程
- 高效稳定的通信协议实现
- 支持多种 WCH 微控制器型号

安装
----

```shell
cargo install --git https://github.com/ch32-rs/wlink
```
