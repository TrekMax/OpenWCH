
OpenWCH
=======

OpenWCH 是面向 WCH 系列芯片构建的现代化 SDK，提供统一的工程结构与开发体验，支持 CMake 构建与 Kconfig 配置。

特性
----

- 统一的组件化 SDK 目录与可复用模块
- CMake 构建体系，支持跨平台与多工具链
- Kconfig 配置系统，支持菜单化配置与配置裁剪
- 示例工程覆盖常见外设与协议场景
- 文档与工具链脚本配套，便于快速上手

支持芯片
----

计划覆盖 WCH 主流系列芯片（例如 CH57x / CH58x / CH59x 等）。

快速开始
----

1. 安装依赖与工具链
2. 克隆仓库并初始化子模块（如有）
3. 选择目标芯片与示例工程
4. 配置 Kconfig 选项
5. 使用 CMake 构建与下载

构建与运行
----

推荐使用 out-of-source 构建方式。

- 生成构建目录
- 配置目标芯片与构建选项
- 编译与链接
- 烧录与调试

Kconfig 配置
----

Kconfig 用于裁剪功能、选择驱动与配置系统参数。

- 配置入口
- 默认配置
- 生成的配置文件

项目结构
----

- components/    组件与驱动
- docs/          文档与指南
- examples/      示例工程
- tools/         构建与辅助工具

示例工程
----

按芯片与外设分类组织，覆盖常用场景：

- ADC / PWM / UART / SPI / I2C
- BLE / USB / 低功耗等
